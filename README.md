# 🏰 بوت حرب القرى - Clash Bot

بوت تلجرام للعبة بناء واستراتيجية شبيهة بـ Clash of Clans.

## المميزات الحالية (MVP)
- قرية شخصية بموارد (ذهب + إكسير) تتراكم تلقائياً مع الوقت
- بناء وترقية: منجم ذهب، مُجمّع إكسير، معسكر جيش، مدفع
- تدريب جيش: برابرة ورماة
- نظام هجوم مبسط ضد لاعبين عشوائيين (نهب موارد + كؤوس)
- لوحة متصدرين

## خطوات التشغيل

### 1. احصل على توكن البوت
- افتح تلجرام وابحث عن `@BotFather`
- أرسل `/newbot` واتبع التعليمات
- انسخ التوكن الذي يعطيك إياه

### 2. جهّز البيئة
```bash
pip install -r requirements.txt
```

### 3. ضع التوكن
افتح `config.py` وضع التوكن مكان `ضع_توكن_البوت_هنا`،
أو استخدم متغير بيئة:
```bash
export BOT_TOKEN="التوكن_هنا"
```

### 4. شغّل البوت
```bash
python bot.py
```

### 5. جرّبه
افتح تلجرام، ابحث عن بوتك، وأرسل `/start`

## هيكل الملفات
- `bot.py` - البوت الرئيسي (الأوامر والأزرار)
- `database.py` - إدارة قاعدة بيانات SQLite
- `game_logic.py` - حسابات الموارد، الترقيات، القتال
- `config.py` - إعدادات التوكن

## أفكار للتطوير القادم
- نظام حماية (Shield) بعد الهجوم عليك
- درع ذهبي يمنع الهجوم لفترة
- المزيد من أنواع المباني (الأسوار، مستودع الموارد)
- نظام تحالفات (Clans) وحروب جماعية
- تحويل التخزين من SQLite إلى PostgreSQL عند نمو عدد اللاعبين
- إضافة صور/أيقونات للقرية بدل النص فقط
- استضافة دائمة على Railway أو VPS (البوت يحتاج يشتغل 24/7)
